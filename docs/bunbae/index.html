새 분배

① 스크린샷 넣기
「보상 분배」 창 스크린샷을 Ctrl+V로 붙여넣거나, 끌어다 놓거나, 눌러서 선택하세요.
📷 캡처 예시 보기 · 「보상 분배」 창만 보이게 캡처하면 인식이 더 정확해요
  • 게임 안 「보상 분배」 창 테두리까지만 캡처해 주세요 (Win+Shift+S 등).
  • 노란 칸: 왼쪽 보상 리스트 맨 위 3칸 → 제목·「다음 아이템 추가」
  • 파란 칸: 오른쪽 파티원 이름 → 이름 칩
  • 전체 화면 캡처도 창을 자동으로 찾지만, 창만 자르면 더 빠르고 정확해요.
  • 시스템 메시지가 글자를 가리지 않을 때 찍으면 좋아요.
② 파티원 이름 클릭 = 분배자 · ✎ 수정 · ✕ 삭제
