마비노기 분배 계산기입니다. 「보상 분배」 창 스크린샷이나 직접 입력으로 파티원·전리품을 기록하고, 분배자를 지정해 경매장 수수료·쿠폰을 반영한 1인당 분배금을 계산합니다. 결과는 링크나 정산 카드 이미지로 공유할 수 있습니다. 스크린샷 인식 결과는 확인 후 사용해 주세요.

스크린샷은 서버에 저장되지 않습니다. 붙여넣은 이미지는 이 브라우저 안에서만 글자 인식(OCR)에 쓰이고, 기록은 브라우저 저장소에만 남습니다. 공유 링크는 분배 내용을 주소(# 뒤)에 담는 방식이라 서버에 따로 보관하지 않습니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.

마비노기 분배 방법

파티 사냥이나 던전에서 나온 전리품은 보통 한 사람(분배자)이 받아 경매장에 팔고, 판매 대금을 파티원 수만큼 나눠 보내는 방식으로 정산합니다. 이때 경매장은 판매 금액에서 수수료를 떼고 지급하므로, 판매가를 그대로 나누면 분배자가 손해를 봅니다. 그래서 수수료를 뺀 실수령액을 기준으로 나누는 것이 일반적입니다. 이 도구는 그 과정을 다음 순서로 계산합니다.

  • 기본 수수료 = 판매가 × 수수료율(「멤버십 4%」 또는 「일반 5%」, 소수점 이하 버림)
  • 쿠폰을 쓰면: 경매장 수수료 10·20·30·50·100% 할인 쿠폰마다 할인액(기본 수수료 × 할인율)에서 쿠폰 최저가를 뺀 「이득」을 계산해, 이득이 가장 큰 쿠폰을 ★ 추천으로 고릅니다. 이득이 0 이하인 쿠폰뿐이면 「쿠폰 없음」이 추천됩니다.
  • 실제 수수료 = 기본 수수료 − 쿠폰 할인액 + 쿠폰 가격
  • 실수령 = 판매가 − 실제 수수료
  • 1인당(수표) = 실수령 ÷ 인원수를 만 골드 단위로 내린 값입니다. 수표로 보내기 쉽게 만 단위로 맞추고, 정확한 값이 다르면 옆에 「정확히 ○○」로 같이 보여 줍니다.

인원수에는 분배자 본인도 포함합니다. 분배자는 자기 몫을 남기고 나머지 파티원에게 1인당 금액을 보내면 됩니다. 쿠폰 최저가는 넥슨 Open API 경매장 시세를 불러와 쓰고, 「⟳ 시세」로 다시 불러올 수 있습니다. 쿠폰 표의 줄을 누르면 추천 대신 그 쿠폰으로 계산합니다.

언제 쓰면 좋나요?

던전이 끝난 직후, 누가 무엇을 가져갔고 누가 팔아서 나눠 줄지 기록해 둘 때 씁니다. 나중에 판매가 끝나면 각자 받을 금액이 바로 나오므로 말로 정산하다 꼬이는 일을 줄여 줍니다. 판매가가 큰 아이템은 수수료 할인 쿠폰 한 장으로 수십만 골드가 달라지기도 해서, 팔기 전에 쿠폰을 살지 정할 때도 유용합니다.

어떻게 쓰나요?

  • 스크린샷 기록: 「보상 분배」 창만 보이게 캡처해 Ctrl+V로 붙여넣으면 파티원 이름과 맨 위 보상 아이템을 자동으로 읽어 옵니다. 인식은 브라우저 안에서만 처리되며, 직접 입력도 됩니다.
  • 분배자 지정: 판매와 분배를 맡은 사람을 👑 분배자로 표시해, 누구에게 골드를 받아야 하는지 분명히 합니다. 켜진 아이템(최대 3개)으로 제목이 자동으로 채워지고, 직접 고친 제목은 그대로 유지됩니다.
  • 수수료 반영: 판매가와 인원수를 넣으면 수수료·실수령·1인당이 바로 나오고, 추천 쿠폰도 표시됩니다. +1억·+1000만 같은 버튼으로 금액을 빠르게 더할 수 있습니다. 1인당 옆 「복사」를 누르면 숫자만 복사됩니다.
  • 진행중 / 완료: 판매 전에는 「저장 (진행중)」, 정산이 끝나면 「완료」로 저장합니다. 목록 위 필터로 전체·진행중·완료만 골라 볼 수 있고, 완료한 기록은 「되돌리기」로 다시 진행중으로 바꿀 수 있습니다.
  • 🔗 공유: 분배 한 건을 짧은 링크로 만들어 복사합니다. 받은 사람은 링크만 열면 같은 내역을 읽기 전용으로 보고, 「＋ 내 목록에 추가」로 자기 목록에 담을 수 있습니다. 「🖼 이미지 포함 공유」를 쓰면 작은 미리보기 이미지를 넣는 대신 링크가 길어집니다.
  • 🖼 결과 캡처: 수수료 계산기의 「결과 캡처」를 누르면 총 판매금액·쿠폰·쿠폰 가격·빠진 수수료·실수령·1인당 분배금과 이미지 저장시간(한국 시간)이 담긴 정산 카드 이미지를 만듭니다. 이미지와 1인당 금액이 함께 클립보드에 들어가 디스코드나 채팅에 바로 붙여넣을 수 있고, 복사가 막힌 환경에서는 PNG 파일로 저장됩니다.

예시

4인 파티가 아이템을 1,200,000골드에 팔았고 수수료가 일반 5%라면 수수료는 60,000골드, 실수령액은 1,140,000골드입니다. 1인당 정확한 몫은 285,000골드이고, 화면의 1인당(수표)에는 만 단위로 내린 280,000골드가 나오며 옆에 「정확히 285,000」이 함께 표시됩니다. 분배자는 자기 몫을 빼고 세 명에게 보내면 됩니다. 이 정도 금액이면 할인 쿠폰 값이 할인액보다 비싸 「쿠폰 없음」이 추천됩니다.

판매가가 1억 골드, 4명, 멤버십 4%라면 기본 수수료는 400만 골드입니다. 10% 할인 쿠폰 최저가가 254,900골드라면(설명용 시세) 할인액 40만 − 쿠폰 254,900 = 145,100골드 이득이라 이 쿠폰이 추천되고, 실제 수수료는 400만 − 40만 + 254,900 = 3,854,900골드, 실수령은 96,145,100골드가 됩니다. 1인당 정확한 몫은 24,036,275골드, 수표 단위로는 24,030,000골드입니다. 이 내역을 공유 링크나 정산 카드로 파티 채팅에 올려 두면 확인이 끝납니다.

한계

  • 스크린샷 인식은 해상도·UI 크기에 따라 이름이나 아이템을 잘못 읽을 수 있으니 결과를 확인해 주세요.
  • 공유 링크가 너무 길면 이미지를 줄이거나 글자만 담아 공유합니다.
  • 쿠폰 시세는 경매장 최저가 기준이라 실제로 그 값에 살 수 있는지는 경매장에서 확인해 주세요.
  • 기록은 이 브라우저에 저장됩니다.

자주 묻는 질문

스크린샷이 서버로 올라가나요?
인식은 브라우저 안에서 이루어지며, 링크 공유 때는 링크 안에 축소 이미지만 담깁니다.
1인당 금액이 실수령 ÷ 인원과 조금 달라요.
수표로 보내기 쉽게 만 골드 단위로 내린 값입니다. 정확한 값은 옆의 「정확히 ○○」에 나옵니다.
추천 쿠폰이 「쿠폰 없음」이에요.
판매가가 작으면 쿠폰 가격이 할인액보다 커서 쓰는 쪽이 손해입니다. 쿠폰 표의 「이득」이 플러스인 쿠폰이 있을 때만 추천됩니다.
링크 복사가 안 돼요.
자동 복사가 막힌 환경이면 링크 창이 뜹니다. 직접 복사해 주세요.
