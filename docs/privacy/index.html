개인정보처리방침

시행일 · 최종 수정: 2026년 10월 28일

마비노기 생활도우미(https://mabi-life.com/, 이하 “사이트”)는 회원가입·로그인 기능이 없으며, 이름·연락처 등 개인을 직접 식별하는 정보를 서버에 수집·저장하지 않습니다. 다만 방문 통계와 광고를 위해 Google의 서비스를 사용하며, 이 과정에서 쿠키 등 자동 생성 정보가 처리될 수 있어 아래와 같이 안내합니다.

1. 운영자 및 사이트 성격

본 사이트는 개인이 운영하는 비공식 팬 도우미 사이트로, 넥슨(NEXON) 및 마비노기 공식 서비스와 관련이 없습니다.

2. 수집하지 않는 정보

  • 회원가입, 로그인, 문의 양식이 없으므로 이름·이메일·전화번호·게임 계정 정보 등을 입력받거나 서버에 저장하지 않습니다.
  • GPS 등 정밀 위치 정보를 수집하지 않습니다.

3. 자동으로 처리되는 정보 (Google Analytics 4)

사이트 이용 현황 파악과 개선을 위해 Google Analytics 4를 모든 페이지에서 사용합니다. 이를 통해 다음과 같은 정보가 Google에 의해 수집·처리될 수 있습니다.

  • 방문 페이지, 체류 시간, 유입 경로 등 이용 기록
  • 기기 종류, 운영체제, 브라우저, 화면 크기, 언어 설정
  • IP 주소에 기반한 대략적인 지역 정보(국가·도시 수준, GPS 아님)
  • 쿠키 및 유사 식별자

운영자는 개인을 식별할 수 없는 통계 형태로만 확인합니다. 자세한 내용은 Google의 파트너 사이트 데이터 사용 방식을 참고하세요. 수집을 원하지 않으면 Google 애널리틱스 차단 브라우저 부가기능을 사용할 수 있습니다.

4. 광고 (Google AdSense) 및 쿠키

사이트 운영비 충당을 위해 Google AdSense를 사용합니다.

  • Google을 포함한 제3자 광고 사업자는 쿠키를 사용하여 이용자의 이 사이트 및 다른 사이트 방문 기록을 바탕으로 광고를 게재할 수 있습니다.
  • Google의 광고 쿠키를 통해 맞춤형 광고가 표시될 수 있습니다.
  • 맞춤형 광고는 Google 광고 설정에서 해제할 수 있으며, 제3자 광고 쿠키는 www.aboutads.info에서 해제할 수 있습니다.
  • Google의 광고 관련 정책: Google 광고 정책

브라우저 설정에서 쿠키 저장을 거부하거나 삭제할 수도 있습니다. 이 경우 일부 광고·통계 기능이 제한될 수 있으나 사이트 이용에는 지장이 없습니다.

5. 브라우저 저장소(localStorage) 이용

사이트의 편의 기능은 이용자 기기의 브라우저 저장소(localStorage)에만 데이터를 저장하며, 운영자 서버로 전송되지 않습니다.

저장 항목용도
즐겨찾기, 직업 정렬 순서, 각종 설정화면 구성 유지
던전 횟수 기록던전 도우미 기록 유지
분배 파티 기록분배 계산기 기록 유지
넥슨 Open API 키(이용자가 직접 입력한 경우에 한함)이용자 기기에서 API 조회 시 사용

이 정보는 해당 브라우저에만 남으며, 브라우저의 사이트 데이터 삭제 기능으로 언제든 지울 수 있습니다. 공용 PC에서는 API 키 입력을 권장하지 않습니다.

6. 넥슨 Open API 데이터

경매장 시세는 운영자가 서버 측에서 넥슨 Open API로 조회해 공용 데이터 파일(prices.json)로 제공하며, 이용자는 이 파일을 내려받아 볼 뿐입니다. 이 과정에서 이용자의 정보는 넥슨에 전송되지 않습니다. (Data based on NEXON Open API)

7. 호스팅 및 접속 기록

사이트는 GitHub Pages에서 호스팅됩니다. 호스팅 제공자(GitHub)는 보안 및 서비스 운영을 위해 IP 주소 등 접속 기록을 보관할 수 있으며, 운영자는 이 기록에 접근하지 않습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

8. 개인정보의 제3자 제공 및 국외 이전

운영자는 이용자의 개인정보를 제3자에게 판매·제공하지 않습니다. 다만 위 3·4·7항의 Google 및 GitHub 서비스 이용에 따라 쿠키·접속 정보가 해당 사업자(미국 등 해외 서버)에서 처리될 수 있습니다.

9. 이용자의 권리

이용자는 쿠키 차단·삭제, 맞춤형 광고 해제, 애널리틱스 차단, 브라우저 저장소 삭제를 통해 정보 처리를 스스로 제한할 수 있습니다. Google이 보유한 정보에 대한 열람·삭제는 Google 계정 데이터 및 개인정보에서 요청할 수 있습니다.
