뿔피리 도우미

서버별 거대한 외침의 뿔피리(거뿔)를 최근 48시간치 모아 최신순으로 보여 줘요. 서버 고르고 검색해 보세요.

뿔피리 도우미 안내

게임 켜 두고 계속 채팅창 보고 있을 필요 없이, 서버별 거뿔을 한곳에 모아 보는 도구예요. 구구·ㅍㅍ 글이나 구슬 시세, 파티 모집 같은 걸 놓쳤을 때 훑어보기 좋아요.

자세한 사용법 · 한계 · 자주 묻는 질문

어떻게 쓰나요?

위 칩에서 서버(류트·만돌린·하프·울프)를 고르면 그 서버 거뿔이 최신순으로 나와요. 검색칸에 단어를 넣으면 그 단어가 들어간 글만 남아요. 마지막으로 고른 서버는 브라우저에 기억해 둬요. /horn/#horn-울프처럼 주소로 바로 열 수도 있어요.

한계

  • 넥슨 Open API를 10분마다 모으는 거라 최대 10분쯤 늦을 수 있어요.
  • 최근 48시간치만 보관하고, 한 번에 최신 300건까지만 보여 줘요.
  • 보낸 사람 아이디를 누르면 클립보드에 복사돼요(귓속말할 때 편해요). 아이디는 48시간 지나면 글과 같이 지워져요.

자주 묻는 질문

구슬 시세 계산은 어디서 하나요?
제작 도우미의 정가 코인 계산기에서 거뿔 구슬 시세를 자동으로 써요.
제 글을 지우고 싶어요.
48시간 지나면 아이디까지 자동으로 지워져요. 급하면 아래 메일로 문의 주세요.
Data based on NEXON Open API
거뿔 내역은 넥슨 Open API 뿔피리 원문을 10분마다 모은 것이며 48시간 뒤 삭제됩니다.
마비노기 공식 서비스와 관련 없는 비공식 팬 도구입니다.
