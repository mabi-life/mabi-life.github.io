경매장 도우미 안내

경매장 도우미는 유물과 인챈트스크롤 두 하부탭으로 나뉩니다. 유물 탭에서는 무리아스의 유물 옵션을 레벨 구간별 최저가·매물로 보고, 인챈트스크롤 탭에서는 일반·전용 스크롤을 검색·필터해 최저가·매물·거래 시세를 빠르게 확인합니다.

자세한 사용법 · 예시 · 한계 · 자주 묻는 질문

언제 쓰면 좋나요?

유물은 옵션 수치에 따라 호가가 크게 달라 게임 안 경매장만으로는 구간을 찾기 번거로울 때, 인챈트 스크롤은 이름·접두/접미·랭크·효과로 지금 시세를 한눈에 보고 싶을 때 씁니다.

어떻게 쓰나요?

위쪽 하부탭에서 유물(#relic)과 인챈트스크롤(#enchant)을 바꿉니다. 데이터는 넥슨 Open API 경매장 값을 약 10분마다 받아 옵니다.

유물 — 옵션 수치 ÷ 최대치 × 10을 반올림한 레벨로 묶어 최저가·매물 수를 보여 줍니다. 무리아스의 유물과 (이데아) 표기는 합산합니다.

인챈트스크롤 — 이름 검색, 접두/접미, 랭크·효과 필터로 목록을 줄입니다. 표에 구분·이름·랭크·최저가·매물·거래 시세가 나오고, 효과가 있으면 이름 아래에 표시됩니다.

예시

유물 옵션 최대 40에 내 수치가 34면 34÷40×10=8.5 → Lv 9입니다. Lv 9 최저가가 380만·매물 2개이고 Lv 8이 150만·매물 15개라면 Lv 9에 가깝게 호가하는 편이 낫습니다. 인챈트는 「놀라운」으로 검색한 뒤 접두만 고르면 해당 스크롤 시세가 정렬됩니다.

한계

  • 유물 레벨은 이해를 돕는 근사치라 같은 Lv 안에서도 수치·조합에 따라 가격이 다를 수 있습니다.
  • 옵션 두 개가 동시에 좋은 조합 가치는 개별 최저가만으로 판단하기 어렵습니다.
  • 인챈트 효과 필터는 준비된 효과 데이터를 쓰며, 비어 있으면 이름·접두/접미·랭크 위주로 동작합니다.
  • 최저가는 이상치일 수 있고 API 지연·점검 중에는 갱신이 멈출 수 있습니다.

자주 묻는 질문

유물과 인챈트를 한 화면에서 같이 보나요?
아니요. 상단 하부탭으로 나뉩니다.
Lv 10이 풀옵인가요?
반올림이라 최대치의 약 95% 이상이면 Lv 10으로 묶입니다. 진짜 풀옵인지는 매물에서 확인하세요.
이데아와 일반 유물을 따로 보나요?
지금은 합산합니다. 가치가 다르면 게임 안에서 따로 확인하세요.
인챈트 거래 시세는 무엇인가요?
수집된 거래·최저가 기록의 참고값입니다. 표본이 적으면 비거나 들쭉날쭉할 수 있어요.
검색이 안 나와요.
띄어쓰기·접두/접미를 바꿔 보거나 이름 일부만 넣어 보세요. 전용 스크롤은 「전용」으로 표시됩니다.
Data based on NEXON Open API

Lv = 옵션 수치 ÷ 최대치 × 10 (반올림) · 무리아스의 유물 + (이데아) 합산
