내 데이터 백업

알바·물교·던전·분배·제작 기록과 화면 설정을 파일 하나로 내보내고, 다른 브라우저·다른 PC에서 가져올 수 있어요. 파일은 내 기기에만 저장되고 서버로 보내지 않습니다.

가져오면 같은 항목의 기존 기록은 덮어씁니다. 분배 원본 이미지도 함께 담기지만, 이미지가 많으면 파일이 커질 수 있어요.

마비노기 생활도우미는 어떤 사이트인가요?

마비노기를 하면서 매번 계산기를 두드리거나 경매장을 여러 번 뒤져야 했던 일을 줄이려고 만든 비공식 팬 도구 모음입니다.

넥슨 Open API 경매장 시세를 약 10분 간격으로 갱신해, 알바 보상·제작 재료·유물·인챈트 스크롤 시세를 보여 줍니다.

물교·던전처럼 주간으로 반복하는 일정은 진행 기록으로 정리할 수 있습니다.

도구끼리 어떻게 이어지나요?

하루 일과로 보면 순서가 자연스럽습니다.

  • 에린 시간에 맞춰 알바를 돌고
  • 주간 물교는 루트·회차와 재료 준비를 미리 짜 두고
  • 여러 캐릭터의 던전 클리어 현황을 체크하고
  • 파티 전리품은 분배에서 스크린샷으로 기록해 수수료를 빼고 나눈 뒤 링크로 공유하고
  • 모은 재료로 무엇을 만들지는 제작에서
  • 유물 옵션·인챈트 스크롤 시세는 경매장에서 확인하면 됩니다
  • 채팅창에서 놓친 거뿔은 뿔피리에서 다시 보면 돼요

알아 두실 점

모든 시세는 참고용입니다.

API 반영이 늦거나 매물이 적은 아이템은 실제 거래가와 차이가 날 수 있으니, 큰 거래 전에는 게임 안 경매장을 한 번 더 확인해 주세요.

이 사이트는 넥슨이나 마비노기 공식 서비스와 관계가 없습니다.

도구별로 무엇을 해결하나요?

  • 알바 — "지금 어떤 알바가 열려 있고, 무슨 보상이 돈이 되지?"를 한 화면에서 답합니다.
  • 물교 — 주간 한도 안에서 이득 큰 교환부터 싣는 계획과 재료 부족분을 정리합니다.
  • 던전 — 캐릭터가 많아도 이번 주 어디까지 돌았는지 헷갈리지 않게 기록합니다.
  • 분배 — 전리품 기록부터 수수료 뺀 1인당 몫 계산, 파티원 공유까지 끝냅니다.
  • 제작·경매장·뿔피리 — 재료 부족분, 유물·스크롤 시세, 놓친 거뿔을 빠르게 찾습니다.

자주 묻는 질문

무료인가요? 가입이 필요한가요?
모두 무료이고 가입·로그인 없이 바로 쓸 수 있습니다.
제 기록은 어디에 저장되나요?
즐겨찾기·숨기기 같은 화면 설정과 알바·물교·던전·분배·제작 기록은 지금 쓰는 브라우저 저장소에만 남고 서버로 보내지 않습니다. 분배 공유 링크는 내용이 링크 안에만 담기며, 방문 통계·광고(Google)용 정보는 별도로 수집될 수 있습니다. 다른 브라우저·PC로 옮기려면 위 「내 데이터 백업」에서 내보내기·가져오기를 쓰면 됩니다.
시세는 얼마나 자주 바뀌나요?
경매장 시세는 약 10분, 거뿔은 약 5분 간격으로 자동 갱신됩니다.
공식 사이트인가요?
아니요. 넥슨과 관계없는 비공식 팬 도구입니다.
