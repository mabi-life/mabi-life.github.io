파티 전리품 분배 기록하는 법

작성: 2026년 11월 3일 · 운영: 하프서버 위즈니

파티 사냥 후 "누가 무엇을 팔아서 얼마씩 나눠 주기로 했지?"가 헷갈린 적이 있다면 분배 도우미가 도움이 됩니다.

1. 왜 기록이 필요한가요?

파티 전리품은 보통 한 명이 맡아서 팔고, 팔린 뒤 수수료를 뺀 금액을 파티원에게 나눠 줍니다. 그런데 판매까지 며칠이 걸리기도 하고, 여러 던전을 연달아 돌면 어떤 아이템이 어느 파티 몫인지 기억하기 어렵습니다. 처음부터 기록을 남겨 두면 분배자도 파티원도 서로 확인하기 쉬워지고, 오해로 생기는 다툼도 줄어듭니다.

2. 스크린샷으로 기록하기

던전 보상 화면을 캡처해 분배 도우미에 붙여넣으면 파티원 이름과 전리품을 글자 인식으로 읽어 기록합니다. 이 인식은 이용자의 브라우저 안에서만 처리되고, 이미지는 서버에 저장되거나 업로드되지 않습니다. 잘못 읽힌 이름이나 아이템은 직접 고칠 수 있습니다.

3. 분배자 지정과 수수료 계산

판매를 맡을 사람을 분배자로 지정하고, 아이템이 팔린 가격을 입력하면 경매장 수수료를 뺀 실수령액과 1인당 몫이 계산됩니다. 예를 들어 4인 파티에서 100만 골드에 팔린 아이템이 있다면, 수수료를 뺀 금액을 4로 나눈 값이 각자의 몫이 됩니다. 계산은 도구가 하므로 분배자는 입력만 하면 됩니다.

수수료와 1인당 몫 계산 화면

4. 링크로 공유하기

정리가 끝나면 공유 링크를 만들어 파티원에게 보내세요. 링크에는 분배 내용이 주소 자체(# 뒤)에 담겨 있어 서버에 따로 보관되지 않고, 받은 사람은 링크를 열기만 하면 같은 내용을 볼 수 있습니다. 기록은 내 브라우저 저장소에 남으므로 브라우저 데이터를 지우면 함께 사라진다는 점만 기억해 주세요.

5. 체크리스트

  • 던전이 끝나면 바로 보상 화면을 캡처한다
  • 분배자와 판매 예정 아이템을 먼저 정해 둔다
  • 팔린 가격을 입력해 수수료 뺀 몫을 확인한다
  • 공유 링크를 파티원에게 보내 내용을 함께 확인한다
