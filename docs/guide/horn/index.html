마비노기 거뿔(거대한 외침의 뿔피리) 검색하는 법

최종 수정: 2026년 11월 16일 · 대상 도구: 뿔피리 도우미

뿔피리 도우미는 마비노기 서버별 거대한 외침의 뿔피리(거뿔)를 한곳에 모아 검색하는 도구예요. 구구·ㅍㅍ 글이나 구슬 참고 시세, 파티 모집을 놓쳤을 때 찾아볼 수 있어요. 이 글의 화면 캡처에서는 보낸 사람 아이디를 가렸어요.

1. 거뿔이란, 무엇을 모아 주나요?

거뿔은 ‘거대한 외침의 뿔피리’의 줄임말로, 같은 서버의 모든 채널에 메시지를 띄우는 아이템이에요. 거래(구구·ㅍㅍ), 파티 모집, 길드 홍보가 주로 올라오지만 채팅창에서 금방 밀려나서 지나간 글을 다시 찾기 어려워요. 이 도우미는 넥슨 Open API로 서버별 거뿔을 자동으로 모아 최근 48시간치를 보여 줘요. 수집은 약 5분 간격으로 자동 실행되고, 방금 외친 거뿔은 다음 수집 때 목록에 올라오므로 최대 5분 남짓 늦게 보일 수 있어요. 오래된 글은 48시간이 지나면 보낸 사람 아이디와 함께 자동으로 지워져서, 개인 정보가 길게 남지 않도록 했어요. 한 번에 최신 300건까지만 보여 줘요. 300건을 넘어간 더 오래된 글은 48시간이 지나지 않았더라도 목록 밖이 될 수 있어요.

2. 서버·분류·검색으로 거뿔 찾기

왼쪽 칩에서 서버(류트·만돌린·하프·울프)를 고르면 그 서버 거뿔이 최신순으로 나와요. 처음 열면 하프 서버가 보이고, 마지막으로 고른 서버는 브라우저에 기억해 둬요. /horn/#horn-울프처럼 주소로 바로 열 수도 있어요. 「전체·파티모집·구매·판매」 칩으로 글 종류를 거를 수 있고, 고른 분류도 다음에 열 때 기억해요. 검색칸에 단어를 넣으면 그 단어가 들어간 글만 남고, 몇 건이 남았는지 아래에 나와요. 분류와 검색은 함께 적용돼요.

글의 보낸 사람 아이디를 누르면 클립보드에 복사돼요. 게임에서 귓속말 대상에 붙여 넣으면 돼요.

3. 분류는 어떻게 나누나요?

분류는 글 안의 단어를 보고 자동으로 정해요. 「딜러 2명 구함」, 「힐 1 ㄱㅎ」처럼 직업·역할 이름 뒤에 구함·모집 같은 말이 붙거나, 크롬바스·크심 「한 바퀴」·「1릴」 모집처럼 던전 모집 표현이 있으면 파티모집이에요. 「삽니다·사요·구매·매입·ㅅㅅ」 같은 표현은 구매, 「팝니다·팔아요·판매·ㅍㅍ·처분·떨이」 같은 표현은 판매로 봐요. 단어만 보고 판단하기 때문에 사고팔기가 한 글에 섞여 있으면 구매와 판매 양쪽에 다 나올 수 있고, 줄임말이 특이하면 「전체」에서만 보일 수 있어요.

4. 구슬 시세를 거뿔로 볼 때 주의점

거뿔 시세를 볼 때는 같은 아이템이라도 서버마다 값이 꽤 다르다는 점을 기억해 두세요. 하프에서 본 구슬 부르는 값을 류트나 울프에 그대로 적용하기는 어려워요. 검색으로 같은 단어를 여러 서버에서 비교해 보면 대략적인 흐름을 잡을 수 있어요. 다만 거뿔 글은 판매자가 부르는 값이라 실제 체결가와는 다를 수 있고, 사기 거래를 막아 주지는 않으니 거래는 늘 게임 안에서 직접 확인해 주세요. Open API가 제공하지 않은 글이나, 수집 직후에 외친 글은 목록에 아직 없을 수 있어요. 몇 분 뒤 새로고침해 보세요. 네트워크 상황에 따라 수집이 5분보다 조금 더 늦을 수도 있어요.

거뿔은 줄임말이 많아요. 「브리 레흐 구슬」 대신 「브리」, 「탈라 가흐」 대신 「탈라」처럼 짧은 핵심 단어 하나로 찾으면 더 많이 걸려요. 검색은 띄어쓰기까지 그대로 비교해요. 「탈라 구슬」로 안 나오면 「탈라구슬」이나 「탈라」로 다시 찾아보세요. 구슬 시세 흐름을 보고 싶다면 서버를 바꿔 가며 같은 단어로 검색해 비교해 보세요. 제작 도우미의 정가 코인 계산기에서는 거뿔 구슬 시세를 자동으로 써요.

5. 따라 해 보기

  1. 뿔피리 도우미에서 서버 「하프」를 고르세요.
  2. 탈라 가흐 구슬을 팔고 싶다면 분류 「구매」, 검색 「탈라」를 넣어 보세요. 최근 48시간 동안 탈라 구슬을 사겠다고 외친 글만 최신순으로 남아요.
  3. 부르는 값들을 훑어보고 마음에 드는 글의 아이디를 눌러 복사한 뒤, 게임에서 귓속말을 보내면 돼요.
  4. 반대로 사고 싶다면 분류를 「판매」로 바꾸면 돼요. 파티를 찾을 때는 분류 「파티모집」에 던전 이름이나 직업을 검색해 보세요.
