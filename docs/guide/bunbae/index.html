마비노기 분배 계산·경매장 수수료 나누는 법

최종 수정: 2026년 11월 16일 · 대상 도구: 분배 도우미

분배 도우미는 「보상 분배」 창 스크린샷이나 직접 입력으로 파티원·전리품을 기록하고, 분배자를 지정해 경매장 수수료·쿠폰을 반영한 1인당 분배금을 계산하는 도구예요. 결과는 링크나 정산 카드 이미지로 공유할 수 있어요. 스크린샷 인식은 브라우저 안에서만 이루어지고, 서버에 저장되지 않아요.

1. 분배 계산이 필요한 이유

파티 사냥이나 던전에서 나온 전리품은 보통 한 사람(분배자)이 받아 경매장에 팔고, 판매 대금을 파티원 수만큼 나눠 보내는 방식으로 정산해요. 이때 경매장은 판매 금액에서 수수료를 떼고 지급하므로, 판매가를 그대로 나누면 분배자가 손해를 봐요. 그래서 수수료를 뺀 실수령액을 기준으로 나누는 것이 일반적이에요. 판매가가 큰 아이템은 수수료 할인 쿠폰 한 장으로 수십만 골드가 달라지기도 해서, 팔기 전에 쿠폰을 살지 정할 때도 유용해요.

계산 순서는 이래요. 기본 수수료 = 판매가 × 수수료율(「멤버십 4%」 또는 「일반 5%」, 소수점 이하 버림). 쿠폰을 쓰면 경매장 수수료 10·20·30·50·100% 할인 쿠폰마다 할인액(기본 수수료 × 할인율)에서 쿠폰 최저가를 뺀 「이득」을 계산해, 이득이 가장 큰 쿠폰을 ★ 추천으로 고르고, 이득이 0 이하인 쿠폰뿐이면 「쿠폰 없음」이 추천돼요. 실제 수수료 = 기본 수수료 − 쿠폰 할인액 + 쿠폰 가격, 실수령 = 판매가 − 실제 수수료, 1인당(수표) = 실수령 ÷ 인원수를 만 골드 단위로 내린 값이에요. 수표로 보내기 쉽게 만 단위로 맞추고, 정확한 값이 다르면 옆에 「정확히 ○○」로 같이 보여 줘요. 인원수에는 분배자 본인도 포함해요.

2. 스크린샷으로 기록하고 분배자 지정하기

「보상 분배」 창만 보이게 캡처해 Ctrl+V로 붙여넣으면 파티원 이름과 맨 위 보상 아이템을 자동으로 읽어 와요. 창 테두리까지만 캡처하면 인식이 더 정확해요. 노란 칸은 위쪽 보상, 파란 칸은 파티원 이름이에요. 인식은 브라우저 안에서만 처리되며, 직접 입력도 돼요. 스크린샷 인식 결과는 확인 후 사용해 주세요.

이름 칩을 눌러 판매와 분배를 맡은 사람을 👑 분배자로 표시하면, 누구에게 골드를 받아야 하는지 분명해져요. 켜진 아이템(최대 3개)으로 제목이 자동으로 채워지고, 직접 고친 제목은 그대로 유지돼요.

3. 수수료 쿠폰·1인당 금액과 공유

판매가와 인원수를 넣으면 수수료·실수령·1인당이 바로 나오고, 추천 쿠폰도 표시돼요. +1억·+1000만 같은 버튼으로 금액을 빠르게 더할 수 있고, 1인당 옆 「복사」를 누르면 숫자만 복사돼요. 쿠폰 최저가는 넥슨 Open API 경매장 시세를 불러와 쓰고, 「⟳ 시세」로 다시 불러올 수 있어요. 쿠폰 표의 줄을 누르면 추천 대신 그 쿠폰으로 계산해요.

분배 한 건은 짧은 링크로 만들어 복사할 수 있어요. 받은 사람은 링크만 열면 같은 내역을 읽기 전용으로 보고, 「＋ 내 목록에 추가」로 자기 목록에 담을 수 있어요. 「🖼 이미지 포함 공유」를 쓰면 작은 미리보기 이미지가 링크에 담기고, 정산 카드 이미지로도 남길 수 있어요. 공유 링크는 분배 내용을 주소(# 뒤)에 담는 방식이라 서버에 따로 보관하지 않아요. 자세한 내용은 개인정보처리방침을 확인해 주세요. 링크가 너무 길면 이미지를 줄이거나 글자만 담아 공유해요. 스크린샷 인식은 해상도·UI 크기에 따라 이름이나 아이템을 잘못 읽을 수 있으니, 저장 전에 결과를 한 번 확인해 주세요. 쿠폰 시세는 경매장 최저가 기준이라, 실제로 그 값에 살 수 있는지는 게임 안 경매장에서 확인해 주세요.

4. 따라 해 보기

  1. 던전이 끝나면 「보상 분배」 창만 보이게 캡처해 분배 도우미에 Ctrl+V로 붙여넣어요.
  2. 이름과 아이템이 맞는지 확인하고, 분배자를 지정한 뒤 제목을 정리해요.
  3. 판매가와 인원수, 멤버십 4% 또는 일반 5%를 넣고 추천 쿠폰과 1인당(수표) 금액을 확인해요.
  4. 판매 전에는 진행중으로 저장하고, 정산이 끝나면 완료로 바꾼 뒤 공유 링크나 정산 카드로 파티원에게 보여 주면 돼요.

예시(설명용 수치): 판매가가 1억 골드, 4명, 멤버십 4%라면 기본 수수료는 400만 골드예요. 10% 할인 쿠폰 최저가가 254,900골드라면 할인액 40만 − 쿠폰 254,900 = 145,100골드 이득이라 이 쿠폰이 추천되고, 실제 수수료는 400만 − 40만 + 254,900 = 3,854,900골드, 실수령은 96,145,100골드가 돼요. 1인당 정확한 몫은 24,036,275골드, 수표 단위로는 24,030,000골드예요. 이 정도보다 판매가가 작으면 할인 쿠폰 값이 할인액보다 비싸 「쿠폰 없음」이 추천될 수 있어요.

자주 묻는 질문

스크린샷이 서버로 올라가나요?

인식은 브라우저 안에서 이루어지며, 링크 공유 때는 링크 안에 축소 이미지만 담겨요. 기록은 이 브라우저에 저장돼요.

1인당 금액이 실수령 ÷ 인원과 조금 달라요.

수표로 보내기 쉽게 만 골드 단위로 내린 값이에요. 정확한 값은 옆의 「정확히 ○○」에 나와요.

추천 쿠폰이 「쿠폰 없음」이에요.

판매가가 작으면 쿠폰 가격이 할인액보다 커서 쓰는 쪽이 손해예요. 쿠폰 표의 「이득」이 플러스인 쿠폰이 있을 때만 추천돼요.

링크 복사가 안 돼요.

자동 복사가 막힌 환경이면 링크 창이 떠요. 직접 복사해 주세요.
