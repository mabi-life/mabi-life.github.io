마비노기 던전 보상·입장 비용 기록하는 법

최종 수정: 2026년 11월 16일 · 대상 도구: 던전 도우미

던전 도우미는 마비노기 던전 입장·클리어 현황과 쓴 골드, 손익, 전재산을 캐릭터별로 기록하는 도구예요. 크롬바스·크롬바스 심연·글렌베르나·브리레흐·브리레흐 4관(믿음의 균열)·탈라가흐 여섯 곳을 다루고, 기본 보상과 입장 비용을 비교하며 균열의 편린 시세도 확인할 수 있어요. 브리레흐 4관 헤일로 알람은 직접 시작·보정하는 브라우저 타이머예요.

1. 언제 쓰면 좋나요?

부캐까지 여러 캐릭터로 던전을 돌다 보면 누가 이번 주에 어디를 몇 번 돌았는지, 키를 몇 개 사 두었는지 헷갈리기 쉬워요. 캐릭터를 추가해 두면 던전별 클리어 횟수를 체크하고 한눈에 현황을 볼 수 있어요. 진행 기록은 매주 목요일 07:00(한국 시간)에 자동 초기화되고 캐릭터는 유지돼요.

2. 클리어 체크와 칸 누르는 규칙

던전을 돌 때마다 칸을 눌러 횟수를 기록해요. 다음 입장 비용과 기본 보상이 같이 보여서, 몇 회까지 도는 게 나은지 바로 가늠할 수 있어요. 칸 누르는 규칙은 던전마다 달라요. 크롬바스 기본키·글렌 기본키·4관 편린 줄은 칸을 누르면 그 칸까지 채워지고, 마지막 칸을 다시 누르면 하나 취소돼요. 크롬바스 심연·브리레흐·탈라가흐와 글렌 추가키는 2단계라 빈칸 → 구매(테두리) → 사용(채움) 순으로 바뀌어요. 키를 미리 사 두고 아직 돌지 않은 상태를 따로 기록하기 위해서예요. 줄 끝의 ↺는 그 던전의 이번 주 기록만 지워요.

지난주에 사 두고 쓰지 않은 키는 새 주에 「🔑 키 n개 보유 (이월)」로 넘어와요. 누르면 1개를 사용하고, 오른쪽 클릭이나 「↩ 이월」로 되돌릴 수 있어요. 「🎟 남은 무료 키 · 보유 키」에는 크롬바스 기본키·글렌 기본키·판의 상자처럼 무료로 도는 입장이 몇 번 남았는지, 사 두고 아직 안 쓴 키가 몇 개인지 요약돼 있어요.

3. 던전 보상과 입장 비용, 손익 계산

손익 = 클리어 횟수 × 기본 보상 − 입장 비용이에요. 골드는 키를 산 시점에, 보상은 키를 사용한(돈) 시점에 잡혀요. 드롭 아이템은 넣지 않아요.

크롬바스 심연·브리레흐·탈라가흐는 주당 10개까지 키를 살 수 있고, n번째 키 값이 10만 → 20만 → 40만 → 70만 → 100만 → 200만 → 300만 → 500만 → 700만 → 1,000만 골드로 올라가요. 글렌베르나는 기본키와 판의 상자 입장은 무료이고, 추가키 2개는 각각 125만·375만 골드예요. 크롬바스는 기본키로 들어가 입장 비용이 없어요. 브리레흐 4관은 골드 대신 균열의 편린으로 입장해요. 이번 주 1번째와 2번째 입장은 편린 1개, 3번째는 2개, 4번째는 3개처럼 하나씩 늘어나 최대 10개까지 들고, 비용 = 편린 개수 × 편린 시세예요. 편린 시세는 경매장 최저가를 자동으로 불러오고 설정에서 바꿀 수 있어요.

기본 보상의 기본값(1회당)은 크롬바스 58만, 크롬바스 심연 50만, 글렌베르나 100만, 브리레흐 130만, 브리레흐 4관 150만, 탈라가흐 170만 골드예요. 내 기준과 다르면 설정에서 고쳐 쓰면 돼요.

4. 균열의 편린 시세와 4관 헤일로 알람

편린 시세는 균열의 편린 경매장 최저가 추이를 그래프로 보여 줘요. ▽ 골짜기·○ 급변동 표시로 언제 샀는지 참고할 수 있고, 24시간·전체로 구간을 바꿀 수 있어요. 4관 입장에 쓰는 편린의 최저가 흐름이에요.

4관 헤일로 알람은 전체 15분 잔여 시계와 등장 시각표(기본 잔여 14:53부터 63초마다)에 맞춰 알려 줘요. 「시작」으로 15분 잔여 시계를 돌리고, 어긋나면 보정으로 맞추면 돼요. 게임 서버와 연동되지 않고 브라우저에서만 시간을 세요.

5. 전재산과 백업

💰 전재산에 만 골드 단위로 입력하면 변경 시각·금액·증감이 내역으로 쌓여 캐릭터별 재정 흐름을 볼 수 있어요. 5230을 넣으면 5,230만, 1억 2500만이나 1.5억처럼 적어도 알아들어요. 내역은 캐릭터별로 최근 100개까지 남아요. 페이지 아래 요약줄에는 전 캐릭터 전재산 합계, 이번 주 지출과 순이익, ⏳ 다음 리셋 시각이 나와요.

설정에서 던전별 기본 보상(만 골드/회)과 편린 시세를 바꿀 수 있고, 기본값으로 되돌릴 수도 있어요. ⬆ 내보내기로 데이터를 복사하거나 파일로 저장한 뒤 다른 기기에서 ⬇ 가져오기 하면 그대로 옮겨져요. 지난주 데이터를 가져오면 캐릭터만 가져오고 진행 기록은 초기화돼요.

6. 따라 해 보기

  1. 던전 도우미에서 캐릭터를 추가해요.
  2. 던전을 돌 때마다 해당 칸을 체크해요. 미리 산 키는 테두리(구매)로 남겨 두세요.
  3. 4관은 다음 입장 비용(편린 개수 × 시세)과 기본 보상을 비교해 어느 회차에서 멈출지 정해요.
  4. 필요하면 전재산을 만 단위로 적어 두고, 주가 바뀌기 전에 내보내기로 백업해 두세요.

숫자로 보면, 브리레흐를 기본값으로 계산했을 때 1~5번째 키는 10만·20만·40만·70만·100만 골드이고 보상은 회당 130만 골드라 다섯 번 모두 이득이에요(보상 650만 − 키 240만 = +410만). 6번째 키는 200만 골드라 보상 130만보다 70만 비싸요. 화면에 「다음 6회째 200만 → −70만」처럼 다음 키 값과 손익이 같이 나와요.

자주 묻는 질문

기록은 언제 초기화되나요?

매주 목요일 07:00(한국 시간)에 진행 기록이 자동으로 초기화되고, 캐릭터는 그대로 남아요.

키를 사 두고 아직 안 돌렸어요.

심연·브리레흐·탈라가흐와 글렌 추가키는 칸을 한 번 누르면 구매(테두리), 두 번 누르면 사용(채움)이에요. 지난주 남은 키는 새 주에 이월로 표시돼요.

드롭 아이템도 손익에 들어가나요?

아니요. 손익은 클리어 횟수 × 기본 보상 − 입장 비용만 계산하고, 드롭 아이템은 넣지 않아요.
